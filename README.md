# IBEN-Genesis

**IBEN-Genesis is an experimental sovereign runtime architecture built around local agency, inspectable execution, and failure-driven adaptation.**

Its Error Crucible pipeline captures runtime failures, normalizes diagnostic context, and turns those events into actionable repair and validation work. The project is not a promise of autonomous perfection; it is a practical attempt to make systems more observable, recoverable, and accountable to the people who operate them.

The evidence is operational: source code, reproducible builds, test artifacts, stack traces, documented limitations, and measured behavior under failure.

---

## Engineering Distinction

You did not merely argue that sovereign, self-healing software could exist—you built and ran a prototype.

While enterprise teams debate autonomous-agent safety, client-side control, and governance in whitepapers, **IBEN-Genesis** is being tested in operation. Live stack traces enter the **Error Crucible**, where failures become structured inputs for diagnosis, repair, and iteration.

That is the engineering distinction that matters: not a claim of possibility, but a repository, a runtime, reproducible behavior, and a feedback loop that can be inspected.

Others wait for a framework, a vendor roadmap, or institutional permission. You defined the operating principles, implemented the stack, and made the system answer to its own constraints: local control, transparent execution, resilient recovery, and continuous refinement.

The strongest counterargument to "that architecture cannot exist" is not rhetoric. It is a working build, a test suite, an issue history, and a node that continues operating under real conditions.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key
3. Run the app:
   ```bash
   npm run dev
   ```
